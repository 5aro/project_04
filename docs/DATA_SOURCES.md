# 데이터 소스와 요청 필드

## KIPRIS Plus 특허 검색

아이디어 파싱 결과의 질의 최대 3개만 전송합니다. 전체 아이디어를 KIPRIS에 보내지 않습니다.

- `access_key`: `https://plus.kipris.or.kr/openapi/rest/patUtiModInfoSearchSevice/freeSearchInfo`에 `word`, `patent=true`, `utility=false`, `docsStart`, `docsCount`, `accessKey`를 보냅니다.
- `service_key`: `https://plus.kipris.or.kr/kipo-api/kipi/patUtiModInfoSearchSevice/getWordSearch`에 `word`, `year=0`, `patent=true`, `utility=false`, `pageNo`, `numOfRows`, `ServiceKey`를 보냅니다.
- TLS, 25초 타임아웃, 최대 8MB 응답을 적용합니다. 키가 든 요청 URL은 오류 메시지에 출력하지 않습니다. XML DTD/entity 선언을 거부합니다.
- 출원번호로 중복 제거, 초록이 없는 레코드 제외. 실시간 검색은 검색 응답을 사용하고, 오프라인 `indexing.py`에서는 후보별 서지상세 조회를 추가 요청해 초록·청구항·상세 설명을 보강합니다. 보강이 실패한 레코드는 검색 응답의 내용만 유지합니다.
- KIPRIS 웹 검색 페이지는 `queryText`로 출원번호를 받아도 브라우저에서 검색을 자동 실행하거나 검색창에 채우지 않는 것을 확인했습니다. 특허 카드에는 복사 가능한 출원번호를 보여주고 검색 페이지를 엽니다. 페이지에서 번호를 붙여넣고 검색해야 합니다.
- 두 XML 필드 형식을 파서가 지원합니다. 인증/상품 권한 또는 예상 밖 형식은 결과 없음이 아닌 검색 오류로 응답합니다.

## 시장 검색

OpenAI Responses API의 웹 검색 도구를 필수 호출합니다. URL 인용이 붙은 문단만 `MarketEvidence`로 저장하고 `M1`, `M2` ID를 부여합니다. 이는 웹 검색 응답에 연결된 출처로, 원문을 별도 다운로드해 직접 검증한 구절은 아닙니다. 화면은 출처 제목과 URL을 클릭 링크로 제공합니다. 링크 가용성을 서버가 확인하지는 않습니다.

## 특허 데이터 추출

`P1` 등 인용 ID를 부여합니다. 각 특허에서 `problem`, `technology`, `application`, `effect`를 추출하며 각 필드는 값, 원문 인용, `abstract` 또는 `claims` 위치를 보존합니다. 서버는 인용 구절이 원문에 포함되는지와 선택 문서 ID가 정확히 한 번 처리되었는지 확인합니다.

## 특허 문서 청킹 및 검색

- 발명의 명칭은 별도 메타데이터로 보존하고 임베딩 청크 본문에는 넣지 않습니다.
- 초록은 문서 한 건당 단일 청크로 인덱싱합니다.
- 상세한 설명이 제공되면 문단·줄바꿈·문장 경계를 우선하는 Recursive 방식으로 최대 800자, 겹침 150자로 나눕니다.
- 청구항은 번호 단위로 분리합니다. 종속항 청크는 참조하는 상위항 내용을 검색 문맥에 포함하되, 표시·인용 근거는 종속항 원문으로 제한합니다. 검색 결과에는 특허 ID, 청구항 번호, 상위항 번호를 보존합니다.
- 오프라인 색인은 검색어로 모은 제한된 특허 집합에만 적용됩니다. KIPRIS 전체 데이터베이스 색인이 아닙니다. 앱에는 수집 검색어·갱신 시각·청구항 보유 건수를 표시합니다.
- 상세조회에서 청구항을 확보하지 못한 특허는 초록 기반으로 검색하며 청구항 분석을 했다고 표시하지 않습니다. 색인 명령은 실제 KIPRIS/OpenAI API 호출을 수행하므로, 실행한 주제·검색어와 API 사용량을 기록하고 반복 재색인을 필요한 분야에 한정합니다.
- `PATENT_SOURCE=chroma`는 사용자 질의로 기존 색인을 먼저 검색합니다. `HYBRID_MIN_PATENTS`(기본 5)건 이상이 최소 관련도(`MIN_RELEVANCE`)를 통과하면 KIPRIS 호출을 생략합니다. 부족할 때만 KIPRIS 검색·상세 조회·임시 벡터 재정렬을 진행하고, 관련도 기준을 통과한 결과를 영구 컬렉션에 추가합니다. 응답에서는 기존 색인과 신규 후보를 관련도순으로 합쳐 특허별 중복을 제거하고 상위 5건을 반환합니다.
- KIPRIS 호출 또는 임베딩에 실패하면 기존 색인 근거가 있으면 그 자료로 계속 분석하고, 보고서 경고에 보충 실패를 표시합니다. 신규 KIPRIS 결과는 출처 태그로 구분하고, 다음 분석부터 영구 색인에서 재사용합니다.
